# Uplift Modeling: Criteo Dataset

Учебный проект по uplift-моделированию (оценке причинно-следственного эффекта, CATE) на датасете Criteo Uplift Prediction (v2.1).

## 🎯 Цель проекта
Разработка и сравнение алгоритмов uplift-моделирования. Оценка инкрементального эффекта (incremental impact) рекламного воздействия на поведение пользователей. 

В рамках проекта исследуются три независимых подхода (трека):
*   **Track A:** *(уточнить метод, например: Two-Model approach)* — *Andrew*
*   **Track B:** *(уточнить метод, например: Class Transformation)* — *Egor*
*   **Track C:** *(уточнить метод, например: Meta-learners на базе нейросетей)* — *Vlad*

## 📊 Метрики оценки
Для сравнения моделей используются стандартные для uplift-моделирования метрики:
*   Qini curve & Qini coefficient
*   AUUC (Area Under Uplift Curve)
*   Uplift@k
